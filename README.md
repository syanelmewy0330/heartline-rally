# Heartline Rally

A little online kart race for long-distance couples (and friends, up to 5 racers).

**Play:** https://syanelmewy0330.github.io/heartline-rally/

## How to play together
1. Open the game, type your name and pick a racer: Bubbles, Taco, Nimbus or Peanut.
2. Press **Create a room** and send your partner the 4-letter code.
3. Your partner opens the same link and types the code under **Join**.
4. Keep the room creator's window open (their browser hosts the room), then press **Start race**.

Drive with the arrow keys or WASD. Hearts and yellow arrow pads give a speed boost. 3 laps.

Players connect directly browser-to-browser using [PeerJS](https://peerjs.com/). Some strict work or school networks block these connections.
